# AnimalLab — Transgenic Mouse Colony Management System

**Author:** Abril Maitena Betti
*Individual project — Algoritmos y Estructuras de Datos*

## 📋 Overview

AnimalLab is a Java console application built for a company that breeds transgenic mice for sale to laboratories. It lets scientists manage mouse **populations** (colonies) and the individual mice within them, tracking genetic mutations across two practice deliverables:

- **Practice I:** core population/mouse management — create, add, remove, modify, list, and view mice; save/load populations to/from CSV files.
- **Practice II:** extended functionality — sorting and searching, virtual population generation from statistical percentages, and a full **Monte Carlo simulation** of population reproduction over time, including genetic inheritance and mutation tracking.

## 🐭 Domain Model

Each **population** has a name, a responsible person, and a number of days it will spend breeding at the facility (up to 630 days, in multiples of 45 — one reproduction cycle = 45 days).

Each **mouse** has:
- A unique, system-generated reference code
- Birth date, weight (10–500g), body temperature (1–45°C), and a free-text field
- Sex (Male/Female)
- Two chromosomes with possible mutations:
  - **X chromosome:** normal or carrying a sterility mutation (males with the mutated X are sterile; females need both X chromosomes mutated to be sterile)
  - **Y chromosome:** normal or carrying a polygamy-predisposition mutation

## ✨ Key Features

- **CRUD operations** on mice within a population (add, remove, modify, view details, list by reference code)
- **CSV persistence:** open, save, and "save as" population files in a custom plain-text CSV format
- **Sorting:** by reference code (natural order via `Comparable`), by birth date, or by weight (custom `Comparator` classes), with reference code as a tiebreaker
- **Binary search** to locate a mouse by reference code (leveraging the naturally sorted list), and sequential search to check for duplicates
- **Virtual population generation** from user-defined percentages (% male/female, % sterile males, % polygamous males, % sterile female chromosomes)
- **Monte Carlo reproduction simulation:**
  - Forms mouse "families" (Normal, Polygamous, Sterile Male, Sterile Polygamous Male) based on genetic profile
  - Simulates litter sizes via weighted random outcomes specific to each family type
  - Models chromosome inheritance (each offspring randomly inherits one parental chromosome from each side)
  - Runs multiple 45-day reproduction cycles until the population's total breeding period is reached, factoring in sexual maturity delay for newborns
  - Reports population statistics (% male/female, % sterile/polygamous/normal) at each cycle
- **Custom exception hierarchy** for robust input validation and error handling
- **Unit tests (JUnit)** for the CSV, Gender, Mouse, and Population classes

## 🏗️ Architecture

The project is organized into 7 packages, separating concerns for clarity and maintainability:

| Package | Responsibility |
|---|---|
| `Main` | Application entry point and console menu (`MainAnimalLab`) |
| `Laboratory` | Core domain/business logic: `Population`, `Mouse`, and the `Gender`/`Chromosome` enums |
| `InputOutput` | Console input reading (`Input`) and output formatting (`Output`) |
| `CSVAdministration` | File persistence: opening, saving, and "save as" for CSV population files (`CSV`) |
| `Families` | Reproduction logic: abstract `Family` class with 4 concrete subtypes (`NormalFamily`, `PolygamousFamily`, `SterileMaleFamily`, `SterilePolygamousMaleFamily`) |
| `Comparators` | Custom sorting via `ComparatorByWeight` and `ComparatorByBirthdate` |
| `Exceptions` | Custom exception classes (`MouseExceptions`, `PopulationExceptions`, `CSVExceptions`, `InputExceptions`, `FamilyExceptions`), each backed by an enum of specific error types |

## ⚠️ Known Limitations

- Reference codes are auto-generated by the system rather than entered by the user, in order to guarantee uniqueness.
- Population reproduction percentages are printed to the console per cycle rather than rendered as a bar chart (which was an optional/recommended feature).
- Not every method has a corresponding unit test; some simple methods were considered redundant to test.
- The optional Swing GUI was not implemented — this is a console-only application.
- A sixth family type (sterile-female-driven) discussed in class was intentionally not implemented; family assignment in this implementation depends solely on the male mouse's genetic profile.

## 🔧 Tech Stack

Java · JUnit · CSV file I/O · custom exception handling · `Comparable`/`Comparator` interfaces

## 🚀 How to Run

Run the `main` method in `MainAnimalLab` (package `Main`) from your IDE (IntelliJ/NetBeans), or execute the provided `.jar` file directly. Navigate the console menu to create or load a population and manage its mice.
